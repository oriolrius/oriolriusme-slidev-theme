# slidev-theme-oriolrius v0.1.0

First public release of the oriolrius.me identity for [Slidev](https://sli.dev) 52: the square orange frame, Ubuntu
type, flat navy “moments” and an orange band for section dividers, built for a 1920×1080 canvas. It was extracted
from the deck *The Agent That Lied* (a private repository),
where it was developed and tested slide by slide, and now lives in its own repository so other decks can use it.

## Highlights

- **Nine layouts.** `cover`, `section`, `code-focus`, `demo`, `diagram`, `end`, `concepts`, `cards` and `four-grid`,
  plus restyled built-ins (`center`, `two-cols-header`, `dense`). Each one ends on a fixed content line (y 992), so
  nothing collides with the footer.
- **Five components.** `Terminal` (live or illustrative replays), `QuoteCard`, `Ts` (talk-timestamp chips), `Tag`
  (honesty labels: inference, self-reported, opinion, illustrative) and `QrCode`, all auto-registered.
- **Brand on every slide.** The footer is a per-slide layer that carries the framed logo in the variant matching the
  surface (orange on paper, white on navy, all white on the band). It fades with its slide and shows in the overview
  and presenter thumbnails. The browser tab gets a framed “o” favicon and a `%s · oriolrius.me` title template.
- **Works offline.** Ubuntu, Ubuntu Sans Mono, Yanone Kaffeesatz, Roboto and Font Awesome 6 Free are bundled through
  `@fontsource`, plus a small DejaVu subset for the arrows and checks the brand fonts lack.
- **Accessible by construction.** Sizes are CSS variables (no `!important`), text never goes below 20px except
  documented chips, and orange text uses contrast-safe inks per surface (WCAG AA / AA-large).
- **Presenting.** A clicker-aware PageUp/PageDown steps through every click before moving slides, images can be
  zoomed on click, and the `oriolrius-navy` Shiki theme is used for all code.
- **Export-safe.** Animations render in their end state when exporting, and nothing is appended to `<body>` at
  startup, so PDFs have no blank trailing page.
- **Acceptance probe.** `test/probe/probe.cjs` checks every slide at click 0 and at its final click state: overflow,
  one-line h1, font loading, text size floor, contrast, code scrolling, wrapped tokens and straight quotes.
  `pnpm probe` builds the showcase and runs it.
- **Showcase.** `test/slides.md` renders every layout, prop, component and class with real content; `README.md` is the
  full API.

## Breaking changes / upgrade steps

None (first release). To use it in a deck:

```bash
pnpm add slidev-theme-oriolrius@github:oriolrius/oriolriusme-slidev-theme#v0.1.0
```

Then set `theme: oriolrius` in the headmatter and keep `shamefully-hoist=true` in the deck's `.npmrc`. If pnpm
resolves `markdown-it` 15, add the override `"pnpm": { "overrides": { "markdown-it": "^14.1.0" } }`: Slidev
52.20's `@comark/markdown-it` does not load with markdown-it 15.

## Repository tooling

MIT license. Conventional Commits checked by commitizen. Pre-commit hooks run gitleaks on staged changes and file
hygiene checks, and gitleaks scans the full history on pre-push. GitHub Actions repeats the scans and builds the
showcase on every push.

## How it was verified

- `pnpm probe` locally: showcase built, “all slides pass” (both click states, every slide).
- GitHub Actions on `main` and on the tag: gitleaks (history and tree) clean, pre-commit hygiene, `cz check`, and the
  showcase build + probe in Chromium, all green.
- Consumed from GitHub by *The Agent That Lied*: the deck builds, its probe passes on all slides, and the cover and
  the densest slide (12) were exported and checked visually.
